# Contributing

The full contributor guide lives at
[`CONTRIBUTING.md`](https://github.com/xstructured/xstructured/blob/main/CONTRIBUTING.md)
in the repository root (also readable directly on GitHub). It covers:

- the development commands (`ruff`, `flake8`, `pyrefly`, `pytest`) and the
  `ruff` version pin rationale;
- building the documentation (`mkdocs build --strict`) and rendering Mermaid
  diagrams (`node scripts/render-diagrams.mjs`);
- requirements for adding or changing example scripts;
- pull request expectations.

See also the [Changelog](https://github.com/xstructured/xstructured/blob/main/CHANGELOG.md)
for released and unreleased changes.
