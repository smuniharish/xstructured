# Security policy

## Supported versions

Security fixes are released for the latest minor version of xstructured.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately through
[GitHub security advisories](https://github.com/smuniharish/xstructured/security/advisories/new),
or by email to samamuniharish@gmail.com. Include a description of the issue, the affected
version, and steps to reproduce it.

You will receive an acknowledgement within five working days. Once a fix is available, it
is released and the advisory is published with credit to the reporter, unless you prefer
to remain anonymous.

For guidance on using xstructured safely, see the
[security documentation](https://xstructured.readthedocs.io/en/latest/security/).
